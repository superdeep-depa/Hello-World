# Analisis Karakteristik Platform Aplikasi

| Aspek | Web | Desktop | Mobile |
| :--- | :--- | :--- | :--- |
| **Arsitektur** | Client-Server (Front-End & Back-End), Event-Driven | Standalone / Client-Server, Event-Driven | Client-Server / Standalone, Event-Driven |
| **Bahasa Utama** | HTML, CSS, JavaScript, TypeScript (React/Vue/Angular) | Java (JavaFX/Swing), C# (.NET), C++, JS/HTML (Electron) | Kotlin (Android Native), Swift (iOS Native), Dart (Flutter), JS (React Native) |
| **Distribusi** | URL/Domain via Web Browser (tidak butuh instalasi) | File installer (.exe, .msi, .dmg, .AppImage) atau Store | Application Store (Google Play Store, Apple App Store, APK) |
| **Keunggulan** | Akses cepat tanpa instalasi, cross-platform otomatis, update aplikasi secara terpusat (real-time) | Akses penuh ke hardware lokal, eksekusi cepat, performa tinggi, dapat berjalan offline penuh | Akses sensor perangkat lengkap (GPS, Kamera, Biometrik), highly portable, notifikasi push |
| **Keterbatasan** | Keterbatasan akses hardware, sangat bergantung pada koneksi internet dan performa browser | Perlu proses instalasi, pembaruan versi manual/re-install, konsumsi memori/ruang penyimpanan lokal | Perbedaan performa hardware device beragam, batasan layar/ukuran UI, manajemen daya/baterai |
| **Contoh Aplikasi** | Tokopedia, Gmail, Figma Web, Facebook | VS Code, Adobe Photoshop, Spotify Desktop, IntelliJ IDEA | WhatsApp, Gojek, Instagram, Mobile Legends |
